## הערות

- ה-DB הכיל כבר נתוני `seed.py` (1000 משתמשים ב-id 1001–2000, 500 חדרים, 25,000 הודעות).
  משתמשי הדמו נוצרו **על גביהם**, ולכן קיבלו 2001–2006. `seed.py` **לא** הורץ מחדש — הרצתו מוחקת את כל הטבלאות.
- לפי TODO-7, רשימת אנשי הקשר בפרונט היא Mock מקומי (דרישת האפיון §9.1), אבל ה-IDs חייבים להיות
  אמיתיים ב-DB — אחרת `POST /api/room/` נופל ב-500 על הפרת Foreign Key. חמשת ה-IDs 2002–2006 הם אלה.
- נוצר חדר בדיקה אחד לאימות השלב: `id: 1001`, `name: "בדיקת שלב 0"`, משתתפים 2001 ו-2002.

## הרצת השרת

`main.py` מייבא `app_config`, `room`, `user` וכו' — קבצים שיושבים תחת `backend/modules/`,
שהיא ה-source root של הפרויקט ב-PyCharm. לכן הפקודה מ-`TASKS-FRONT.md` שלב 0 נכשלת ב-`ModuleNotFoundError`
כשמריצים אותה משורת הפקודה. הפקודה העובדת, מתוך `backend/`:

```bash
PYTHONPATH=modules ./.venv/Scripts/uvicorn.exe main:app --reload --host 127.0.0.1 --port 8000
```

הרצה מ-PyCharm (`python main.py`) עובדת כמו שהיא, כי PyCharm מוסיף את `modules/` ל-`PYTHONPATH` אוטומטית.
