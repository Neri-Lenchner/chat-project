# DESIGN SYSTEM — "קו" (Kav Chat)

**גרסה:** 1.1
**מסמך אב:** `SPECV2-FRONT.md`
**מימוש ייחוס:** קבצי ה-HTML בתיקיית `frontend/` + `css/tokens.css`
**מצב:** סגור לעיצוב. כל מימוש קוד חייב לגזור ממנו, לא להמציא ערכים חדשים.

---

## 1. הכיוון העיצובי

**המוצר:** אפליקציית צ'אט אישית. הזדהות במספר טלפון, שיחות אחד-על-אחד.
**המשתמש:** אדם שפותח את המסך כדי לענות למישהו, לא כדי לחקור ממשק.
**התפקיד היחיד של המסך:** להראות מי כתב, מה נכתב ומתי — ולהתפנות.

**התזה:** צ'אט הוא יומן זמן. השעה איננה מטא-דאטה קטנה בפינת בועה — היא ציר הקריאה.
מכאן נגזר האלמנט החתימתי (סעיף 6).

**עקרונות שנשמרים לאורך כל המערכת:**

1. **משפחת פונט אחת** — Rubik. היררכיה נבנית ממשקל, גודל וצבע, לא מפונט שני. מספרים משתמשים
   באותו פונט עם ספרות טבלאיות (`tabular-nums`), כדי שעמודות של שעות ותאריכים יתיישרו.
2. **שני משטחים בלבד** — משטח שקוע (`--color-canvas`) שעליו יושבים כרטיסים לבנים, ומשטח לבן
   מלא לאזור העבודה. כל גבול במערכת הוא או קו של 1px או מעבר בין שני המשטחים האלה.
3. **אקסנט אחד + הדגשה אחת** — כחול קובלט עמוק לפעולות ולמצב פעיל, ענבר אך ורק לדברים שלא נקראו.

מה שנפסל בכוונה: לוח קרם עם סריף ואקסנט טרקוטה, ממשק כהה עם אקסנט ניאון, ובועות ירוקות
בסגנון וואטסאפ.

## 2. טוקנים

כל הערכים יושבים ב-`css/tokens.css` תחת `:root`. **אין ערך צבע / מרווח / רדיוס / פונט קשיח בשום קובץ אחר.**
שינוי מראה = שינוי טוקן.

והכרטיס הפעיל. הענבר מופיע רק כשיש הודעות שלא נקראו. שום אייקון, כותרת או מסגרת לא נצבעים "לנוי".

### 2.2 טיפוגרפיה

**משפחה אחת בלבד: `Rubik`** (`--font-ui`). אין פונט כותרות נפרד ואין פונט מונו.

| תפקיד | משקל | גודל |
| --- | --- | --- |
| כותרת פאנל / מסך | 700 | `--fs-2xl` / `--fs-xl` |
| כותרת שיחה, כותרת כרטיס | 600 | `--fs-lg` / `--fs-md` |
| שם בכרטיס שיחה, תווית שדה, כפתור | 500–600 | `--fs-base` / `--fs-sm` |
| גוף, הודעות | 400 | `--fs-base` |
| שעות, תאריכים, מטא | 400 | `--fs-xs` |

הסולם — שמונה מדרגות בלבד, אין ערכי ביניים:

`--fs-micro 11` · `--fs-xs 12` · `--fs-sm 13` · `--fs-base 15` · `--fs-md 17` · `--fs-lg 20` · `--fs-xl 28` · `--fs-2xl 40`

גובה שורה: `--lh-tight 1.2` לכותרות · `--lh-snug 1.35` · `--lh-body 1.55` לגוף ולהודעות.

**כלל המספרים:** כל מספר שנסרק אנכית — שעה, תאריך, מונה, מספר טלפון — מקבל את המחלקה `.u-num`
(`tabular-nums`). זה מה שמחליף את פונט המונו: אותה משפחה, רוחב ספרה אחיד, עמודות שמתיישרות.

### 2.3 מרווחים

סולם של 4: `4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64` (`--sp-1` … `--sp-16`).
אין מרווח שאינו על הסולם. מרווח פנימי של כרטיס: `--sp-5`. בין קבוצות במסך: `--sp-6`.

### 2.4 רדיוס

`--radius-sm 8` (אייקון, שלד) · `--radius-md 12` (כפתור, שדה, מונוגרמה) · `--radius-lg 16` (בועה, שורת שיחה, כרטיס) ·
`--radius-xl 22` (דיאלוג, פאנל תצוגה) · `--radius-full` (תג, טוסט, כפתור עגול) ·
`--radius-tail 5` — פינת ה"זנב" של בועת הודעה בצד השולח.

## 3. RTL — כללים מחייבים

1. `<html lang="he" dir="rtl">` בכל מסך.
2. **אין `left` / `right` / `margin-left` בקוד רכיבים.** רק תכונות לוגיות:
   `inset-inline-start`, `padding-inline`, `border-inline-end`, `margin-block`.
   החריג היחיד המכוון: קו פס הזמן ב-`.thread__inner::before`, שמעוגן פיזית לעמודת השעות.
3. **בועות:** הודעה נכנסת בצד ההתחלה (ימין), הודעה יוצאת בצד הסיום (שמאל). זו התנהגות RTL תקנית.
4. אייקון החץ "חזרה" מצביע **ימינה**. אייקון השליחה מסובב ב-`scaleX(-1)`.
5. מספרי טלפון, שעות ותאריכים תמיד `tabular-nums` ובכיוון LTR טבעי בתוך הטקסט.

## 4. רכיבים

לכל רכיב יש מחלקה אחת, וריאנטים ב-`--modifier` ומצבים ב-`is-*`. אין עיצוב מקומי לרכיב בתוך מסך.

### 4.1 כפתור `.btn`

וריאנטים: `--primary` `--secondary` `--ghost` `--danger` `--icon` `--round` `--block` `--sm`.
מצבים: `:hover` · `:active` (הזזה של 1px) · `[disabled]` (55% שקיפות) · `.is-loading`.

מבנה חובה:

```html
<button class="btn btn--primary">
  <span class="btn__spinner spinner"></span>
  <span class="btn__label">כניסה</span>
</button>
```

ב-`.is-loading` הכפתור נחסם ללחיצה, התווית מתעמעמת והספינר מופיע — **מונע שליחה כפולה** (סעיף 15 באפיון).

### 4.2 שדה `.field`

מבנה: `.field__label` → `.field__wrap` (`.input` + `.field__icon`) → `.field__hint` → `.field__error`.
מצב שגיאה: מוסיפים `is-invalid` ל-`.field` — המסגרת אדומה, הרקע `--color-danger-wash`,
ה-hint מוחלף בהודעת השגיאה, והקלט מקבל `aria-invalid="true"`.
הוולידציה מוגדרת דקלרטיבית: `data-validate="required phone"` ו-`data-label="מספר טלפון"`.

### 4.3 באנר `.banner`

הודעת מצב ברמת המסך (כישלון טעינה, כישלון מחיקה, כישלון הרשמה).
וריאנטים: ברירת מחדל, `--error`, `--warn`. מכיל כותרת (`.banner__title`), הסבר (`.banner__text`)
וכפתור פעולה כשיש דרך להתאושש. תמיד עם `role="alert"`.

### 4.4 מונוגרמה `.avatar`

ריבוע מעוגל עם ראשי תיבות, לא עיגול ולא תמונה. הגוון נגזר מ-`otherUserId` בעזרת `avatarTone()`
כדי שאותו איש קשר יקבל תמיד את אותו צבע. גדלים: `--sm 32` · ברירת מחדל `44` · `--lg 56`.

### 4.5 כרטיס שיחה `.room`

`div` עם `role="button"` ו-`tabindex="0"` (ולא `<button>`, כי יש בתוכו כפתור מחיקה).
זהו **כרטיס** ולא שורת רשימה: משטח לבן, מסגרת `--color-line`, רדיוס `--radius-lg`, `--shadow-card`,
ריפוד `--sp-4`, ומרווח `--sp-3` בין כרטיס לכרטיס. הוא יושב על עמודה בצבע `--color-canvas`,
וזה מה שנותן לו את ההפרדה.

| מצב | מראה |
| --- | --- |
| מנוחה | מסגרת `--color-line` + `--shadow-card` |
| hover | הרמה של 1px, `--shadow-lift`, מסגרת `--color-line-strong` |
| פעיל (`aria-current="true"`) | מסגרת `--color-accent`, `--shadow-lift`, פס אקסנט ברוחב `--border-active` בקצה ההתחלה, השם בצבע האקסנט |
| יש הודעות שלא נקראו | פס `--color-highlight` בקצה ההתחלה + תג מונה בענבר |
| לחיצה ארוכה (`is-pressing`) | כיווץ ל-99% + `--shadow-1` |

עמודות הכרטיס: מונוגרמה · שם + הודעה אחרונה · שעה או תאריך + תג/כפתור מחיקה.

### 4.5.1 כרטיס איש קשר `.contact`

אותה שפה בדיוק, בגרסה שקטה יותר כי הוא יושב בתוך דיאלוג לבן: רקע `--color-surface-sunken`,
מסגרת `--color-line`, ובמעבר עכבר הופך ללבן עם מסגרת אקסנט ו-`--shadow-card`.
**כל שינוי בכרטיס השיחה חייב להיות משוקף כאן.**

### 4.6 בועה `.bubble` בתוך `.msg`

`.msg--in` נכנסת · `.msg--out` יוצאת · `.msg--pending` בשליחה (60% שקיפות, שעה `···`) ·
`.msg--failed` נכשלה (רקע אדום רך + כפתור `.msg__retry`).
רוחב מקסימלי `min(64ch, 74%)`.

### 4.7 דיאלוג `.scrim` + `.dialog`

מרכוז מלא, `--shadow-pop`, סגירה ב-Escape ובלחיצה על הרקע, מיקוד חוזר לאלמנט שפתח.
כפתורי הפעולה בשורה אחת, רוחב שווה. הכפתור ההרסני אף פעם לא ראשון בסדר הקריאה.

### 4.8 נוספים

`.menu` תפריט משתמש · `.toast` אישור קצר (3.2 שניות) · `.badge` מונה · `.chip` תווית מונו ·
`.skeleton` שלד טעינה · `.empty` מצב ריק · `.spinner`.

## 5. פריסות המסכים

### 5.1 מסכי כניסה — הרשמה, התחברות

```
┌───────────────────────────────┬──────────────────────┐
│  לוגו                          │  כותרת גדולה          │
│  כותרת + משפט הסבר             │                      │
│  [באנר שגיאה — מוסתר]          │  תצוגה מקדימה חיה     │
│  שדות (48px, מרווח 20)         │  של שיחה על פס הזמן   │
│  [כפתור ראשי ברוחב מלא]        │                      │
│  קישור למסך השני               │  משפט מונו קטן        │
└───────────────────────────────┴──────────────────────┘
        משטח לבן                        פאנל פורצלן
```

מתחת ל-900px הפאנל נעלם והטופס תופס את כל הרוחב.

### 5.2 מעטפת האפליקציה — ראשי, שיחה חדשה, שיחה

```
┌──────────────────────────────────────────────────────┐
│ סרגל עליון 64px:  לוגו | מצב · שיחה חדשה · משתמש▾    │
├────────────────┬─────────────────────────────────────┤
│ עמודת שיחות    │  כותרת שיחה 76px  [🗑]              │
│ 352px          │ ─────────────────────────────────── │
│ רקע canvas     │  הודעות על משטח לבן + פס זמן        │
│ כרטיסים לבנים  │ ─────────────────────────────────── │
│                │  שורת כתיבה 52px, צל כלפי מעלה      │
└────────────────┴─────────────────────────────────────┘
```

**עמודת השיחות נשארת גלויה גם במסך השיחה** — היא מעטפת ולא מסך, וזה מה שמאפשר ניווט בין
שיחות בלחיצה אחת. הראוטים נשארים כפי שהוגדרו באפיון.

שלושת הגבולות של מסך השיחה מוגדרים במפורש, כדי שאף אזור לא "יימס" לתוך השני:

1. **בין העמודה לאזור העבודה** — מעבר משטח (אפור מול לבן) + קו 1px.
2. **בין הכותרת להודעות** — קו 1px + `--shadow-1`, והכותרת גבוהה (76px) עם שם בגודל `--fs-lg`.
3. **בין ההודעות לשורת הכתיבה** — קו 1px + `--shadow-bar` (צל כלפי מעלה).

**שורת הכתיבה היא האלמנט הכי בולט בתחתית המסך, בכוונה:** גובה 52px (גבוה מכל שדה אחר),
מסגרת `--border-width-strong`, רדיוס `--radius-xl`, רקע שקוע שהופך ללבן במיקוד,
וכפתור שליחה **עם תווית "שליחה"** ולא אייקון בלבד. במובייל התווית יורדת והכפתור נשאר ריבוע 52px.

מתחת ל-760px מוצג מסך אחד בכל רגע: `home` מציג את הרשימה, `chat` מציג את השיחה עם חץ חזרה.

## 6. האלמנט החתימתי — פס הזמן

באזור ההודעות קיימת **עמודת שעות ברוחב 60px בצד הסיום**, ובתוכה קו אנכי אחד שרץ לאורך כל השיחה.
השעה של כל הודעה — נכנסת או יוצאת — יושבת על אותו קו, במונו, ביישור אחד.
מפרידי התאריך יושבים על אותו קו כנקודה.

**למה:** האפיון דורש שעה לכל הודעה (סעיף 11) ותאריך או שעה לכל שיחה (סעיף 7.2).
במקום לפזר שעות זעירות בתוך בועות, הן הופכות לציר קריא: אפשר לראות בסריקה אחת
אם השיחה הייתה רצף מהיר או התכתבות שנמשכה יום.

**כללי שימוש:** הקו לא מצויר כשאין הודעות. השעה מקבלת רקע בצבע המשטח כדי לחתוך את הקו מאחוריה.
ראש הקו מסומן בתווית מקווקוות "תחילת השיחה", כי ההיסטוריה נטענת במלואה ואין גלילה אינסופית.
אין להוסיף לעמודה הזו שום דבר נוסף — לא אייקוני מסירה, לא אווטארים.

## 7. מצבים — חובה בכל מסך

| מצב | טיפול |
| --- | --- |
| **טעינה ראשונית** | שלד (`.skeleton`) בצורת התוכן שעומד להגיע. אף פעם לא ספינר על מסך ריק |
| **פעולה בתהליך** | `.is-loading` על הכפתור שיזם אותה, הכפתור חסום |
| **ריק** | `.empty` עם כותרת, משפט הסבר ופעולה אחת שמוציאה מהמצב |
| **שגיאה ברמת מסך** | `.banner--error` עם כותרת, סיבה וכפתור ניסיון חוזר |
| **שגיאה ברמת שדה** | `.field.is-invalid` עם הודעה שמסבירה מה לתקן |
| **שגיאה בפעולה נקודתית** | טוסט `--error` + סימון הפריט (למשל `.msg--failed`) |

**כלל:** אין להציג טעינה מחדש למידע שכבר קיים ב-Redux (סעיף 22 באפיון). המעבר בין שיחות מיידי.

## 8. שפת הכתיבה בממשק

- כפתור אומר מה יקרה: "כניסה", "מחיקה", "שליחת הודעה". לא "אישור" ולא "שלח טופס".
- הודעת שגיאה מסבירה מה קרה ומה עושים: *"מספר הטלפון לא תקין. הפורמט הנדרש: 0501234567"*.
- אין התנצלויות, אין "אופס", אין קריאות. אין מונחים טכניים (`404`, `timeout`) מול המשתמש.
- מצב ריק הוא הזמנה לפעולה, לא הודעת מצב: *"עוד לא התחלת שיחה"* ואז כפתור.
- אותה פעולה שומרת על אותו שם לאורך כל הזרימה: "שיחה חדשה" בכפתור, בתפריט ובכותרת הדיאלוג.

## 9. נגישות

- מיקוד מקלדת נראה תמיד (`:focus-visible`, מסגרת אקסנט 2px עם ריווח 2px).
- ניגודיות: `--color-ink` על `--color-canvas` ו-`--color-on-accent` על `--color-accent` עוברים AA.
  `--color-ink-3` מותר לטקסט משני בגודל 12 ומעלה בלבד.
- שורת שיחה נגישה במקלדת: Enter פותח, Delete פותח דיאלוג מחיקה.
- לדיאלוג יש `role="dialog"`, `aria-modal`, סגירה ב-Escape והחזרת מיקוד.
- לכל שגיאה `role="alert"`; לכל שדה שגוי `aria-invalid`.
- אזור לחיצה מינימלי 36px, ובמובייל 44px.

## 10. מעבר למימוש React + TypeScript

הפרוטוטייפ הוא HTML/CSS/JS כדי לבדוק עיצוב ומצבים. במימוש בפועל, לפי סעיף 2 באפיון:
**TypeScript בלבד, axios, React Router, React Hook Form, Redux Toolkit.**

מיפוי מחייב:

| קובץ בפרוטוטייפ | יעד |
| --- | --- |
| `css/tokens.css` | נשאר כפי שהוא, מיובא פעם אחת ב-`main.tsx`. **לא להמיר ל-CSS-in-JS** |
| `css/base.css` `components.css` `screens.css` | `styles/` — או פירוק ל-CSS Modules לפי רכיב, עם אותן מחלקות |
| `js/icons.js` | `components/Icon/Icon.tsx` עם אותו `ICONS` ו-`type IconName` |
| `.room` / `.contact` | `components/RoomCard` + `components/ContactCard` — אותן מחלקות מצב |
| `js/ui.js` — ולידציה | כללי `register()` של React Hook Form, אותן הודעות מילה במילה |
| `js/ui.js` — פורמט תאריך | `utils/date.ts` — `formatTime`, `formatRoomStamp`, `formatDayLabel` |
| `js/ui.js` — Session | `utils/storage.ts` + `userSlice` |
| `js/screens.js` — Store | `roomSlice` + `messageSlice`. אותה סמנטיקה: טעינה פעם אחת, עדכון מקומי |
| `register/login/home/new-chat/chat.html` | `screens/Register` `Login` `Home` `NewChat` `Chat` |
| שורת שיחה, בועה, שלד, באנר | `components/RoomItem` `MessageItem` `Loading` `ErrorMessage` |

**מה אסור בזמן המימוש:**

1. להוסיף צבע, גודל פונט, מרווח או רדיוס שלא קיים ב-`tokens.css`.
2. לכתוב `left` / `right` בקוד רכיב.
3. לשנות טקסט שגיאה בלי לעדכן את סעיף 8 כאן.
4. לבנות מצב טעינה כספינר גדול במקום שלד.
5. לצבוע אלמנט באקסנט מעבר לשלושת השימושים שהוגדרו בסעיף 2.1, או להשתמש בענבר למשהו
   שאינו "לא נקרא".
6. להוסיף משפחת פונט שנייה, כולל פונט מונו לשעות. `tabular-nums` פותר את זה.
7. להקטין את שורת הכתיבה או להחליף את כפתור השליחה באייקון בלבד בדסקטופ.

## 11. מה עוד לא הוכרע

- **מצב כהה.** מערכת הטוקנים מוכנה לזה (כל צבע עובר דרך משתנה), אבל לא הוגדרה ערכה כהה.
- **אינדיקציית מסירה/נקראה.** לא קיימת באפיון; אם תיכנס — מקומה בתוך הבועה ולא בעמודת השעות.
- **חיפוש שיחות.** לא באפיון. אם ייכנס, מקומו בראש עמודת השיחות בגובה `--size-control-sm`.
- **קיבוץ הודעות רצופות מאותו שולח.** כרגע כל הודעה עומדת בפני עצמה, כי כל שעה חייבת לשבת על פס הזמן.
